# W3 采购清单：220V 三芯进线（11-24）

> 用途：市电 220V → 开关电源 AC 输入端（L / N / ⏚FG）
> 这是 24V 供电线之外，W3 硬件线还缺的第二根线。**市电有触电/短路风险，接错比 24V 那根严重得多，务必按第五节核对。**

## 〇、先看电源 AC 入口长什么样（决定买哪种）

开关电源的 220V 入口常见两种，**买错插不进去**：

| 入口形式 | 怎么认 | 买哪种 |
|---|---|---|
| **螺丝端子**（明纬 LRS 类最常见） | 三个螺丝孔，旁边印 `L` `N` `⏚`/`FG` | 一端国标三脚插头、另一端三根裸线（剥线镀锡） |
| **品字尾插座**（IEC C14） | 一个"品"字形凹进去的三孔插座 | 成品线：一端国标三脚插头、另一端品字尾公头，**免剥线** |

> ✅ **11-24 照片已确认：你的电源是螺丝端子式**——端子排从左到右清楚印着 `L (AC)`（红标）、`N`（黑标）、接地符号 `⏚`，**没有品字尾插座**。旁边的 `V- V- V+ V+` 是 24V 输出，`ADJ` 是输出电压微调电位器（**别乱拧**）。
> 所以 220V 线就买**螺丝端子版**：一端国标三脚插头、另一端三根裸线剥线镀锡——即第二节的主话术。品字尾那版作废，不用管。

## 一、买什么（规格）

| 项 | 规格 | 为什么 |
|---|---|---|
| 线径 | **3×0.75mm²** 三芯铜软线（RVV 3×0.75）；想更结实买 3×1.0mm² | 24V 电源满打满算 240W，220V 侧约 1.1A，0.75mm² 载流 ~10A，余量充足 |
| 芯数 | **必须三芯**（火/零/地） | 地线是保命线，不能只接两根 |
| 一端 | **国标三脚插头**，10A 250V，带接地脚 | 插墙面插座，接地脚必须真接黄绿地线 |
| 另一端 | 螺丝端子式→三根裸线剥 6–8mm 并镀锡；品字尾式→品字尾公头 | 见第〇节 |
| 颜色 | 棕=火线 L、蓝=零线 N、黄绿双色=地 ⏚ | 国标/IEC 配色；若商家用红代棕也可，但通电前必须核对（见第五节） |
| 长度 | 1 米 | 桌面够用 |
| 认证 | 带 CCC 国标认证 | 市电线别买三无 |

## 二、复制发给商家客服

**螺丝端子式电源：**
> 老板好，我要一根 220V 电源线：**3×0.75mm² 三芯铜软线**，**一端国标三脚插头（10A 250V 带接地）**，**另一端三根裸线剥线 6–8mm 并镀锡**。棕接火线 L、蓝接零线 N、黄绿双色接地线。长度 1 米，要带 CCC 认证的。

**品字尾式电源（把上面这句换成）：**
> 老板好，我要一根成品电源线：**一端国标三脚插头（10A 250V），另一端品字尾（IEC C14 公头）**，**3×0.75mm² 三芯**，长度 1 米，带 CCC 认证。

## 三、搜索关键词

- `3x0.75 三芯电源线 国标三插 1米`
- `RVV 3×0.75 三芯软线 带三插`
- 品字尾式：`国标三插 转 品字尾 电源线 3x0.75`

价格参考：10–20 元包邮。这是标准件，不必买贵的。

## 四、别买错

- ❌ 别买**两芯线**（没地线）——金属外壳电源不接地，漏电时外壳带电
- ❌ 别用**手机充电线 / USB 线**替代——那是 5V 弱电、且多为两芯（豆包明确说过的红线）
- ❌ 别买**细于 0.75mm²** 的线
- ❌ 别买 **DC 插头线**——那是低压直流，不是 220V 交流
- ❌ 电源是螺丝端子就别买品字尾成品线，反之亦然（第〇节）

## 五、到手后接线 + 首次上电（安全，逐步来）

**接线（全程断电，插头绝不插电）：**
1. 确认墙面插座这一端先不插电。
2. 裸线端每根剥 6–8mm 并镀锡（商家已做好的跳过）。
3. 棕 → 电源 `L`；蓝 → 电源 `N`；黄绿 → 电源 `⏚`/`FG`。
4. 逐根拧紧螺丝，轻拉确认不松动、**铜丝不外露**、没有毛刺搭到相邻端子。
5. 插头端若需自己接：同样棕 L / 蓝 N / 黄绿 地，压紧后把线卡扣扣好。

**首次插电前用万用表导通档（蜂鸣档）核对——不通电！**
6. 插头 L 脚 ↔ 电源 L 端子：应导通；N ↔ N：导通；地脚 ↔ ⏚：导通。
7. 插头 L 脚 ↔ N 脚：**不导通**；L ↔ 地脚：**不导通**（否则短路，禁止上电）。

**上电：**
8. 确认无误后，先把 24V 输出端和电机都断开（空载），再插 220V。
9. 看电源指示灯亮、用万用表直流档量 AC 输出应无异常；**不要带电去量 220V 端子本身**。
10. 一切正常再接回 24V 侧，回到 `W3硬件操作卡-11-24.md` 的安全顺序继续。

> 有任何一步对不上（颜色不确定、导通关系不对、螺丝拧不紧），**停下来**——市电不比 24V，宁可白天清醒时找人当场核对，不要凌晨凭猜硬上。
