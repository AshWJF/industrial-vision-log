## W1｜11.13–11.22｜环境 + 概念（node / topic / service）

**必须掌握**
- node / topic / service 三者的区别（发布订阅 vs 请求应答）
- 话题通信：publisher / subscriber 的代码骨架（rclpy）
- `.msg` / `.srv` 里 `---` 的上下结构（请求 | 响应）
- `ros2 run` / `ros2 topic list / echo / info` / `ros2 node list`
- 为什么先 `source /opt/ros/humble/setup.bash`

**了解即可**
- QoS 的历史与默认值；`demo_nodes_cpp` 是自带的 C++ 示例节点

**明确不学**
- 自定义 interface 包、composition（节点组合）、参数服务器高级用法——都往后放
- 🖐 手写要求：**无**（这步用 AI 完全没问题）

## W2｜11.23–11.29｜图像进 ROS + D435i 上手

**必须掌握**
- 一条完整图像管线：采集 → cv_bridge → OpenCV 处理 → 发布；每条话题全名（注意 `/camera/camera/...` 两层）
- cv_bridge 为什么存在；`bgr8` / `mono8` / `16UC1` 各对应什么；深度图为什么用 16 位
- topic / service / param 之别；为什么 `align_depth.enable` 走 launch（后处理 filter 开关）
- 「对齐深度」对齐了什么（彩色图 (x,y) 与深度图同坐标指同一点）
- tf2 管什么；`view_frames` 画坐标树、读 `frames.pdf`
- rosbag 录 / 放；`-o` 相对路径的坑
- launch 的作用与带参启动（`serial_no:=...` 整体加引号的坑）
- 三组必设参数各自的物理意义：`visual_preset=3`（高精度）、关自动曝光、`align depth→color`
- 深度失效机理：反光金属 / 透明件 / 吸光 / 超量程；缺失率怎么定义
- 内参 K（fx/fy/cx/cy）与 `尺寸 = px × Z / fx` 的推导
- 重复性 vs 准确度的区别
- image_transport：装好（`list_transports`）≠ 会用（rqt 切 `compressed` 出图）

**了解即可**
- image_transport 压缩插件与带宽权衡、`republish`；内参标定（W14 才正式学）；三层依赖 D435i→librealsense2→realsense2_camera→节点；GenICam/harvesters

**明确不学**
- 标定、亚像素、YOLO（都不在本周）；§2.1 只学 5 件事：节点通信 / cv_bridge / tf2 / launch / rosbag
- 🖐 手写要求：无

## W3｜11.30–12.06｜MuJoCo 最小可用（S1 仿真）

> 目标只有一句话：一周后在 rviz2 里看到 MuJoCo 渲染的画面，而且画面来自 ROS topic。学到这条就停手。

**必须掌握**
- `pip install mujoco` 跑官方 demo
- 读一个 MJCF（XML），改质量 / 摩擦 / 颜色 / 加相机
- Python API：`MjModel` / `MjData` / `mj_step`
- 离屏渲染 `mujoco.Renderer` 拿 RGB + 深度
- 写 ROS2 桥：定时器里 step，发布 `/image_raw` 和 `/joint_states`

**了解即可**
- 为什么用仿真先代替真机（接口不变、随时换）

**明确不学**
- 强化学习、dm_control、MJX、域随机化、Isaac Sim（**全都不学**，等 W37 再深入）

## W4｜12.07–12.13｜数字图像与色彩（S2 开始，🖐 开始多）

**必须掌握**
- 采样 / 量化、位深（8 位 / 16 位）
- RGB / HSV / Lab 三个色彩空间的含义与适用场景

**明确不学**：深度学习、标定（后面周）

## W5｜12.14–12.20｜滤波与卷积

**必须掌握**
- 卷积定义（翻转、滑动、乘加）、边界处理（补 0 / 复制 / 镜像）
- 可分离核（高斯核拆成两个一维，加速原理）
- 均值 / 高斯 / 中值 / 双边滤波各自用途
- 锐化 / 拉普拉斯
- 椒盐噪声 / 高斯噪声及对应去法

**了解即可**：双边滤波与引导滤波的关系（选学）

**明确不学**：深度学习
- 🖐 **手写 3×3 卷积**（含边界处理）

## W6｜12.21–12.27｜边缘与特征

**必须掌握**
- Sobel / Scharr 梯度算子
- **Canny 三步**：高斯平滑 → 梯度幅值方向 → NMS + 双阈值（滞后）
- NMS（非极大值抑制）原理
- 双阈值 + 边缘连接（滞后阈值）
- Harris / Shi-Tomasi 角点
- **亚像素角点**（cornerSubPix 思路）
- ORB 特征 + RANSAC 求单应（匹配两张工件图）

**了解即可**：SIFT 为什么被 ORB 替代（专利 + 速度）

**明确不学**：深度学习
- 🖐 **手写 Canny 的 NMS + 双阈值**；手写亚像素角点精化
