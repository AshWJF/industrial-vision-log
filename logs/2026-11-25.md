## 硬件实物口径（按到货实物，不按采购规格）

- 220V：红 L / 黄 N / 绿 地；24V：红 +V / 绿 −V。各段两端贴标签，不靠颜色记。
- 插头：带船型开关（O/I），L/N 丝印实物读不出，靠⏚符号 + 开关通断变化认端子。
- 万用表：UT33B 的 200Ω 档损坏（其他档正常）→ 换新表 **Pro'sKit MT-1210**，有蜂鸣通断档，测通断一响就通。

## 已完成（按操作卡顺序）

### 1. 认插头端子 + 接 220V 进线
- 地：⏚符号定位；L：船型开关开时通、关时断的那个端子；N：剩下一个。
- 交叉验证：L↔N、L↔地、N↔地 全不响，确认没短路。
- 接线：红→L、黄→N、绿→地，剥 6–8mm、铜丝捻紧、插到底不露铜、拧紧后轻拉不出。

### 2. 接 24V 输出（电源 → Shield）
- 电源端子排丝印：L、N、⏚、−V、−V、+V、+V。
- 红→+V（最右孔之一）、绿→−V（中间孔之一）；24V 只接 Shield 的 V+/GND，不进 UNO 的 VIN。
- 端子孔位反复看反两次（斜视图 + 裁剪图），最终以万用表实测收口，不以看图为准。

### 3. 上电前核对（蜂鸣档，插头不插电）
- 220V：插头 L↔电源 L 响、N↔N 响、地↔⏚ 响；L↔N、L↔地 不响。
- 24V：Shield V+↔电源 +V 响、GND↔电源 −V 响；V+↔GND 稳在 **714Ω**（电容充电后的正常负载，非短路）。

### 4. 测调 Vref（A4988，R100）
- USB 必须接（Vref 靠 UNO 的 5V），24V 不用接。
- 直流 2V 档，黑笔 GND、红笔电位器金属十字。
- 初测 0.998V（≈1.25A，偏高）→ 调到 **0.405V ≈ 0.51A**（目标起步值）。

### 5. 首次上电查 24V
- 插头插墙插、船型开关拨 I，直流 20V 档测 Shield V+↔GND = **24.4V**（正常）。

### 6. 断电接电机线 + Ubuntu 跑通
- 完全断电（拔 USB、断 24V、拔插头）后接电机 4 根线到 Shield X 轴接口。
- Ubuntu（VSCode 集成终端）：
  - `python3 -c "import serial"` → 3.5（pyserial 已装）；
  - `ls /dev/ttyUSB*` → `/dev/ttyUSB0`；`ls -l` → dialout 组，权限正常；
  - `$$` → 回 `Grbl 1.1h [...]` + 完整参数表（`$100=250.000`）；
  - `G0 X10 F500` → 回 `ok`，电机启动有声音后停，不发热；
  - 加长 `G0 X50 F300`（10 秒）复测：声音平稳、不发热 → 判定正常启动声，非啸叫。

## 关键判断（勿再反复）
- **Vref 测的是电压不是电流**：拧螺丝 → 测 Vref → 用 `I=Vref/(8×Rs)` 算电流 → 定扭矩上限。空载测，电流不直接测。
- **USB 接不接**：测 Vref / 跑 `$$`+G0 要接（逻辑 5V + 串口）；测 24V 电压不用接；接电机线要全断。
- **端子孔位看图会看反**：一律以万用表实测为准，不改这个规矩。
- **`Grbl 1.1h` 欢迎语每次都有**：打开串口 UNO 自动重启打印，正常，不是故障。
- **714Ω 不是短路**：真短路是接近 0Ω 且一直响；714Ω 是电容充电后的正常负载。
