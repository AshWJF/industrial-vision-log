## 一、W1 收尾：第 8 节 服务入门（只看概念）

- 概念对比：话题 = 单向广播、持续流（图像 / 传感器 / 坐标）；服务 = 请求-响应、一问一答（拍照 / 计算 / 触发动作）。发布者不管有没有人听，客户端必须等服务端回复。
- 实操三步：
  - `ros2 run demo_nodes_cpp add_two_ints_server`（终端 1 起服务端）
  - `ros2 service list`（终端 2 看到 `/add_two_ints`）
  - `ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts "{a: 5, b: 3}"` → 返回 `sum=8`
- `.srv` 结构：`int64 a` / `int64 b` / `---` / `int64 sum`，`---` 上为请求、下为响应。
- 踩坑：`source` 打成了 `setup.bas`（少一个 h）；因为 `.bashrc` 已配好环境，不影响后续命令。
- 结果：W1 主题的 8 节清单全部走完（鱼香ROS 口径；实际主跟的古月居 21 讲仍是 8/21，见第五节）。
